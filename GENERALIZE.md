# Product rule — any Mac

Every Apple Desk change must work for any user on any Mac. A fresh install onboards with `grok-desk onboard`.

Do not hardcode a machine name, a person's accounts, or a timezone as product behavior. Caches stay under `~/.cache/grok-*`. Doctor, dry-run, and timeouts must behave on a Mac that has never run this tool.

The computer used to build and time commands is verification only. If something only works on that computer, label it as verification, not as the product path.
